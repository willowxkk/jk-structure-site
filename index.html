日语 / 韩语句子结构成分总表

这份文档的目标不是完整讲完语法，而是列出你在日语、韩语句子里会反复遇到的“结构成分”。

这里的“结构成分”指：它们不主要负责提供具体事物意义，而是负责告诉你句子里的词语之间是什么关系、动作处于什么状态、说话人是什么语气、前后句子如何连接。

可以把它理解成：

内容词负责“说什么”。

例如：我、你、肚子、饭、猫、雨、喜欢、吃、去、漂亮、饿。

结构成分负责“这些内容词怎么组织起来”。

例如：谁是主体、谁是对象、动作发生在哪里、是不是过去、是不是否定、是不是疑问、语气是否礼貌、前后是否转折。

总框架 / 扫描顺序

0. 最底层框架：一句话通常在说什么

绝大多数句子都可以先粗略拆成这几种：

0.1 什么东西发生了什么

展开 / 收起
中文雨下了。
日语雨が降った。
romajiame ga futta
韩语비가 왔어.
romanizationbi-ga wa-sseo

核心结构：

雨｜发生了“下/来”的动作。

0.2 什么东西是什么样

展开 / 收起
中文肚子饿了。
日语お腹が空いた。
romajio-na-ka ga su-i-ta
韩语배가 고파.
romanizationbae-ga go-pa

核心结构：

肚子｜处在“饿/空”的状态。

0.3 什么人做了什么

展开 / 收起
中文我吃饭。
日语私がご飯を食べる。
romajiwatashi ga gohan o taberu
韩语내가 밥을 먹어.
romanizationnae-ga ba-beul meo-geo

核心结构：

我｜对饭｜做“吃”的动作。

0.4 什么东西是什么

展开 / 收起
中文这是书。
日语これは本です。
romajikore wa hon desu
韩语이건 책이야.
romanizationi-geon chae-gi-ya

核心结构：

这个｜被判断为｜书。

所以阅读日语/韩语时，第一步可以永远问：

这句话在说谁？说什么东西？发生了什么？是什么状态？对象是谁？语气是什么？

助词 / 조사

1. 名词后面的结构标签：助词 / 조사

日语叫：助詞 / じょし / joshi

韩语叫：조사 / jo-sa

它们通常贴在名词后面，告诉你这个名词在句子里的角色。

这是日语和韩语里最关键的一类结构成分。

1.1 主体标记：が / 이、가

展开 / 收起

作用标出前面的词是动作或状态的主体。

日语

お腹が空いた。

romajio-na-ka ga su-i-ta
意思肚子空了 / 我饿了。

雨が降った。

romajia-me ga fut-ta
意思雨下了。
韩语

배가 고파.

romanizationbae-ga go-pa
意思肚子饿 / 我饿了。

비가 왔어.

romanizationbi-ga wa-sseo
意思下雨了。

先记：

が / 이、가 = 前面的东西，是后面动作或状态的主体。

1.2 主题标记：は / 은、는

展开 / 收起

作用把前面的词拿出来，表示“至于它 / 说到它 / 关于它”。

注意：日语 は 在助词里读 wa，不读 ha。

日语

私は学生です。

romajiwa-ta-shi wa ga-ku-sei de-su
意思我呢，是学生。
韩语

나는 학생이야.

romanizationna-neun hak-saeng-i-ya
意思我呢，是学生。

它和 が / 이、가 的区别先不用一次性学完。初期可以这样区分：

が / 이、가：标“谁是主体”。

は / 은、는：把一个话题拿出来说。

例子：

日语

猫がいる。

romajine-ko ga i-ru
意思有猫。重点是“猫出现了”。

猫はいる。

romajine-ko wa i-ru
意思猫是有的。可能暗含“狗没有”或“别的没有”。
韩语

고양이가 있어.

romanizationgo-yang-i-ga i-sseo
意思有猫。

고양이는 있어.

romanizationgo-yang-i-neun i-sseo
意思猫是有的。

1.3 动作对象标记：を / 을、를

展开 / 收起

作用标出前面的词是动作作用的对象。

日语

ご飯を食べる。

romajigo-han o ta-be-ru
意思吃饭。

音楽を聴く。

romajion-ga-ku o ki-ku
意思听音乐。
韩语

밥을 먹어.

romanizationba-beul meo-geo
意思吃饭。

음악을 들어.

romanizationeu-ma-geul deu-reo
意思听音乐。

先记：

を / 을、를 = 前面的东西是被做动作的对象。

1.4 方向、目标、时间点、对象：に / 에

展开 / 收起

这一类很常见，也最容易混。先记它的核心感觉：

に / 에 = 指向一个点。

这个“点”可以是地点、时间点、目标、对象。

日语

学校に行く。

romajigak-kou ni i-ku
意思去学校。

三時に会う。

romajisan-ji ni a-u
意思三点见。

友達に言う。

romajito-mo-da-chi ni i-u
意思对朋友说。
韩语

학교에 가.

romanizationhak-gyo-e ga
意思去学校。

세 시에 만나.

romanizationse si-e man-na
意思三点见。

친구에게 말해.

romanizationchin-gu-e-ge mal-hae
意思对朋友说。

韩语里“给某人/对某人”的对象常用 에게 / 한테。

1.5 动作发生地点、工具、方式：で / 에서、로、으로

展开 / 收起

日语 で 的核心感觉：

动作发生的场所 / 使用的工具 / 完成某事的方式。

日语

家で食べる。

romajii-e de ta-be-ru
意思在家吃。

電車で行く。

romajiden-sha de i-ku
意思坐电车去。

日本語で話す。

romajini-hon-go de ha-na-su
意思用日语说。
韩语

집에서 먹어.

romanizationji-be-seo meo-geo
意思在家吃。

전철로 가.

romanizationjeon-cheol-lo ga
意思坐地铁/电车去。

일본어로 말해.

romanizationil-bo-neo-ro mal-hae
意思用日语说。

先记：

に / 에 更像“点”。

で / 에서 更像“动作发生的场”。

1.6 所属、修饰：の / 의

展开 / 收起

作用表示所属、来源、性质、修饰关系。

日语

私の本。

romajiwa-ta-shi no hon
意思我的书。

日本の音楽。

romajini-hon no on-ga-ku
意思日本的音乐。

赤い服の人。

romajia-ka-i fu-ku no hi-to
意思穿红衣服的人。
韩语

나의 책.

romanizationna-ui chaek
意思我的书。

일본의 음악.

romanizationil-bon-ui eu-mak
意思日本的音乐。

韩语口语里 의 常常弱化或省略，或者读得接近 e。

1.7 和、与、引用：と / 와、과、하고、랑

展开 / 收起

日语 と 有两个非常重要的作用。

1.7.1 表示“和”

日语

友達と行く。

romajito-mo-da-chi to i-ku
意思和朋友去。
韩语

친구와 가.

romanizationchin-gu-wa ga
意思和朋友去。

친구랑 가.

romanizationchin-gu-rang ga
意思和朋友去。更口语。

1.7.2 表示引用内容

日语

行くと言った。

romajii-ku to it-ta
意思他说“去”。/ 他说要去。

好きだと思う。

romajisu-ki da to o-mo-u
意思我觉得喜欢。/ 我觉得是喜欢。
韩语

간다고 했어.

romanizationgan-da-go hae-sseo
意思他说要去。

좋다고 생각해.

romanizationjot-ta-go saeng-gak-hae
意思我觉得好。

日语里口语引用经常用 って。

行くって言った。

romajii-ku tte it-ta
意思他说要去。

1.8 方向：へ / 로、으로、에

展开 / 收起

日语 へ 在助词里读 e，不读 he。

日语

東京へ行く。

romajitou-kyou e i-ku
意思去东京。
韩语

도쿄로 가.

romanizationdo-kyo-ro ga
意思去东京。

に 和 へ 都可以表示去某处。粗略理解：

に 更像到达点。

へ 更像朝某个方向。

日常里很多时候差别不大。

1.9 起点和终点：から、まで / 부터、까지

展开 / 收起
日语

東京から大阪まで。

romajitou-kyou ka-ra oo-sa-ka ma-de
意思从东京到大阪。

一時から三時まで。

romajii-chi-ji ka-ra san-ji ma-de
意思从一点到三点。
韩语

도쿄부터 오사카까지.

romanizationdo-kyo-bu-teo o-sa-ka-kka-ji
意思从东京到大阪。

한 시부터 세 시까지.

romanizationhan si-bu-teo se si-kka-ji
意思从一点到三点。

先记：

から / 부터 = 从。

まで / 까지 = 到。

1.10 也、连、只、都：も、しか、だけ、でも / 도、만、밖에、라도

展开 / 收起

这些属于副助词、限定助词一类。它们负责调节范围。

日语

私も行く。

romajiwa-ta-shi mo i-ku
意思我也去。

これだけ。

romajiko-re da-ke
意思只有这个。

これしかない。

romajiko-re shi-ka na-i
意思只有这个。注意 しか 后面常接否定。

水でも飲む？

romajimi-zu de-mo no-mu
意思喝点水之类的吗？
韩语

나도 가.

romanizationna-do ga
意思我也去。

이것만.

romanizationi-geon-man
意思只有这个。

이것밖에 없어.

romanizationi-geot-ba-kke eop-seo
意思只有这个。

물이라도 마실래?

romanizationmu-ri-ra-do ma-sil-lae
意思要不要喝点水之类的？

1.11 疑问小标记：か / 까、니、냐

展开 / 收起
日语

行きますか。

romajii-ki-masu ka
意思去吗？

口语里也可以不用 か，直接靠升调：

行く？

romajii-ku?
意思去吗？
韩语

가요?

romanizationga-yo?
意思去吗？

갑니까?

romanizationgam-ni-kka?
意思去吗？更正式。

가니? / 가냐?

romanizationga-ni? / ga-nya?
意思去吗？关系亲近或语气较直接。
谓词尾巴 / 判断

2. 动词和形容词的尾巴：活用 / 어미

日语动词、形容词会变形。韩语谓词也会变形。

这个部分很重要，因为你在真实句子里看到的词，经常不是词典形。

例如：

日语

空く / suku = 空、变空

空いた / suita = 空了

韩语

먹다 / meok-da = 吃

먹었어 / meo-geo-sseo = 吃了

阅读时要养成一个动作：

看到变形 → 还原原形 → 再理解这个变形表达了什么。

2.1 过去 / 完成

展开 / 收起
日语

食べる。

romajita-be-ru
意思吃。

食べた。

romajita-be-ta
意思吃了。

行く。

romajii-ku
意思去。

行った。

romajiit-ta
意思去了。
韩语

먹어.

romanizationmeo-geo
意思吃。

먹었어.

romanizationmeo-geo-sseo
意思吃了。

가.

romanizationga
意思去。

갔어.

romanizationga-sseo
意思去了。

2.2 否定

展开 / 收起
日语

食べない。

romajita-be-na-i
意思不吃。

行かない。

romajii-ka-na-i
意思不去。

礼貌否定：

食べません。

romajita-be-ma-sen
意思不吃。
韩语

안 먹어.

romanizationan meo-geo
意思不吃。

먹지 않아.

romanizationmeok-ji a-na
意思不吃。

안 가.

romanizationan ga
意思不去。

2.3 愿望：想做

展开 / 收起
日语

食べたい。

romajita-be-ta-i
意思想吃。

行きたい。

romajii-ki-ta-i
意思想去。
韩语

먹고 싶어.

romanizationmeok-go si-peo
意思想吃。

가고 싶어.

romanizationga-go si-peo
意思想去。

2.4 正在、持续状态

展开 / 收起
日语

食べている。

romajita-be-te i-ru
意思正在吃 / 吃着。

口语缩短：

食べてる。

romajita-be-te-ru
意思正在吃。
韩语

먹고 있어.

romanizationmeok-go i-sseo
意思正在吃。

2.5 经验：做过

展开 / 收起
日语

行ったことがある。

romajiit-ta ko-to ga a-ru
意思去过。
韩语

가 본 적이 있어.

romanizationga bon jeo-gi i-sseo
意思去过。

2.6 可能：能做

展开 / 收起
日语

食べられる。

romajita-be-ra-re-ru
意思能吃 / 可食用。

できる。

romajide-ki-ru
意思能做。
韩语

먹을 수 있어.

romanizationmeo-geul su i-sseo
意思能吃。

할 수 있어.

romanizationhal su i-sseo
意思能做。

2.7 被动：被……

展开 / 收起
日语

言われた。

romajii-wa-re-ta
意思被说了 / 被别人说。

見られた。

romajimi-ra-re-ta
意思被看到了。
韩语

韩语被动形式比较分散，可以先认识这些：

보이다

romanizationbo-i-da
意思被看见 / 看起来。

들리다

romanizationdeul-li-da
意思被听见 / 听得到。

받다

romanizationbat-da
意思接受，也可构成“被……”。

칭찬받았어.

romanizationching-chan-ba-da-sseo
意思被表扬了。

2.8 使役：让某人做

展开 / 收起
日语

食べさせる。

romajita-be-sa-se-ru
意思让某人吃。

行かせる。

romajii-ka-se-ru
意思让某人去。
韩语

먹게 하다.

romanizationmeok-ge ha-da
意思让某人吃。

가게 하다.

romanizationga-ge ha-da
意思让某人去。

시키다

romanizationsi-ki-da
意思使、让、命令做。

2.9 条件：如果、的话

展开 / 收起
日语

行けば。

romajii-ke-ba
意思如果去。

行ったら。

romajiit-ta-ra
意思去了的话 / 如果去。

行くなら。

romajii-ku na-ra
意思如果要去的话。
韩语

가면.

romanizationga-myeon
意思如果去。

간다면.

romanizationgan-da-myeon
意思如果说要去的话。

2.10 命令、请求、禁止

展开 / 收起
日语

行って。

romajiit-te
意思去一下 / 请去。口语请求。

行ってください。

romajiit-te ku-da-sa-i
意思请去。

行くな。

romajii-ku na
意思别去。

食べないで。

romajita-be-na-i de
意思别吃。
韩语

가.

romanizationga
意思去。也可能是命令，靠语气判断。

가 주세요.

romanizationga ju-se-yo
意思请去。

가지 마.

romanizationga-ji ma
意思别去。

2.11 推测、可能性、好像

展开 / 收起
日语

行くかも。

romajii-ku ka-mo
意思可能会去。

行くだろう。

romajii-ku da-rou
意思大概会去。

行くらしい。

romajii-ku ra-shii
意思听说会去 / 好像会去。

行くみたい。

romajii-ku mi-ta-i
意思好像会去。
韩语

갈 것 같아.

romanizationgal geot ga-ta
意思好像会去。

아마 갈 거야.

romanizationa-ma gal geo-ya
意思大概会去。

가겠지.

romanizationga-get-ji
意思应该会去吧。
谓词尾巴 / 判断

3. 判断词 / 系词：是，不是，作为判断

它们负责让句子形成“X 是 Y”的判断。

3.1 日语：だ、です

展开 / 收起

これは本だ。

romajiko-re wa hon da
意思这是书。普通体。

これは本です。

romajiko-re wa hon de-su
意思这是书。礼貌体。

否定：

本じゃない。

romajihon ja na-i
意思不是书。

本ではありません。

romajihon de-wa a-ri-ma-sen
意思不是书。更正式。

3.2 韩语：이다、아니다

展开 / 收起

이건 책이야.

romanizationi-geon chae-gi-ya
意思这是书。口语。

이것은 책입니다.

romanizationi-geo-seun chae-gim-ni-da
意思这是书。正式。

否定：

책이 아니야.

romanizationchae-gi a-ni-ya
意思不是书。
句尾语气

4. 句尾语气成分

句尾成分负责改变语气。它们不一定有稳定中文对应词，但非常影响“这句话听起来是什么态度”。

4.1 日语常见句尾

展开 / 收起

か / ka

表示疑问。

行きますか。

romajii-ki-masu ka
意思去吗？

ね / ne

表示确认、共感、柔和地拉近对方。

いいね。

romajiii ne
意思不错啊 / 好呢。

寒いね。

romajisa-mu-i ne
意思好冷啊，对吧。

よ / yo

表示提醒、告知、把信息推出去。

行くよ。

romajii-ku yo
意思我要去哦 / 我去啦。

な / na

可以表示感叹，也可以表示禁止，取决于位置和语气。

すごいな。

romajisu-go-i na
意思好厉害啊。

行くな。

romajii-ku na
意思别去。

かな / ka-na

表示自言自语式疑问、犹豫。

行こうかな。

romajii-kou ka-na
意思要不要去呢。

じゃん / jan

表示“这不是……嘛 / 原来就是……啊”。口语。

いいじゃん。

romajiii jan
意思不是挺好吗。

ぞ、ぜ / zo、ze

语气较强，偏男性化或漫画感，现实中要看人设和关系。

行くぞ。

romajii-ku zo
意思走了！

4.2 韩语常见句尾

展开 / 收起

韩语句尾比日语更系统，也强烈体现礼貌程度。

요 / yo

礼貌但日常。

가요.

romanizationga-yo
意思去。

좋아요.

romanizationjo-a-yo
意思好 / 喜欢。

니、냐 / ni、nya

疑问。关系亲近或语气较直接。

가니?

romanizationga-ni
意思你去吗？

가냐?

romanizationga-nya
意思去吗？更随便/直接。

까 / kka

正式疑问。

갑니까?

romanizationgam-ni-kka
意思去吗？正式。

지 / ji

确认、推测、共识感，类似“吧 / 对吧 / 是吧”。

좋지?

romanizationjot-ji
意思不错吧？

가겠지.

romanizationga-get-ji
意思应该会去吧。

네 / ne

感叹、确认，有“呢/啊”的感觉。

좋네요.

romanizationjon-ne-yo
意思挺好啊。

군요 / gu-nyo

表示发现、感叹。

그렇군요.

romanizationgeu-reot-gu-nyo
意思原来如此啊。
连接关系

5. 连接前后句子的成分

这一类负责告诉你：前后是并列、先后、原因、转折、条件，还是补充。

5.1 并列、动作连接：て / 고

展开 / 收起
日语

食べて寝る。

romajita-be-te ne-ru
意思吃了再睡。

見て聞く。

romajimi-te ki-ku
意思看并且听。
韩语

먹고 자.

romanizationmeok-go ja
意思吃了睡。

보고 들어.

romanizationbo-go deu-reo
意思看并且听。

5.2 原因：から、ので / 아서、어서、니까

展开 / 收起
日语

雨だから行かない。

romajia-me da-ka-ra i-ka-na-i
意思因为下雨，所以不去。

雨なので行きません。

romajia-me na-no-de i-ki-ma-sen
意思因为下雨，所以不去。较柔和/正式。
韩语

비가 와서 안 가.

romanizationbi-ga wa-seo an ga
意思因为下雨，所以不去。

비가 오니까 안 가.

romanizationbi-ga o-ni-kka an ga
意思因为下雨，所以不去。

5.3 转折：けど、でも、が / 지만、근데、하지만

展开 / 收起
日语

romajia-me da-ke-do i-ku

でも行く。

romajide-mo i-ku
意思但是还是去。
韩语

romanizationbi-ga o-ji-man ga
意思虽然下雨，但去。

근데 가.

romanizationgeun-de ga
意思但是去。

5.4 条件：如果

展开 / 收起
日语

行くなら言って。

romajii-ku na-ra it-te
意思如果你要去，就说一声。

雨だったら行かない。

romajia-me dat-ta-ra i-ka-na-i
意思如果下雨就不去。
韩语

가면 말해.

romanizationga-myeon mal-hae
意思如果去，就说。

비가 오면 안 가.

romanizationbi-ga o-myeon an ga
意思如果下雨就不去。

5.5 让步：即使、就算

展开 / 收起
日语

雨でも行く。

romajia-me de-mo i-ku
意思即使下雨也去。

行ってもいい。

romajiit-te mo ii
意思去了也可以 / 可以去。
韩语

비가 와도 가.

romanizationbi-ga wa-do ga
意思即使下雨也去。

가도 돼.

romanizationga-do dwae
意思可以去。
名词化 / 修饰

6. 名词化：把动作或句子变成“一个事情”

这是日语、韩语非常重要的一类结构。

它的作用是：

把“做某事 / 某个情况”变成一个可以被讨论的名词性对象。

中文里也有类似感觉，比如：

我喜欢“唱歌”。

“你来”这件事很重要。

6.1 日语：の、こと

展开 / 收起

歌うのが好き。

romajiu-ta-u no ga su-ki
意思喜欢唱歌。

行くことにした。

romajii-ku ko-to ni shi-ta
意思决定去。

粗略区别：

の 更贴近日常、具体感、现场感。

こと 更像“事情、事项、概念”。

6.2 韩语：것、기

展开 / 收起

노래하는 것이 좋아.

romanizationno-rae-ha-neun geo-si jo-a
意思唱歌这件事很好 / 我喜欢唱歌。

가기 싫어.

romanizationga-gi si-reo
意思不想去。

먹는 것.

romanizationmeong-neun geot
意思吃的东西 / 吃这件事。
名词化 / 修饰

7. 修饰结构：前面的东西修饰后面的名词

日语和韩语里，修饰语通常放在被修饰名词前面。

7.1 日语修饰名词

展开 / 收起

赤い服。

romajia-ka-i fu-ku
意思红色的衣服。

昨日見た映画。

romajiki-nou mi-ta ei-ga
意思昨天看的电影。

私が好きな曲。

romajiwa-ta-shi ga su-ki na kyo-ku
意思我喜欢的歌。

7.2 韩语修饰名词

展开 / 收起

빨간 옷.

romanizationppal-gan ot
意思红色的衣服。

어제 본 영화.

romanizationeo-je bon yeong-hwa
意思昨天看的电影。

romanizationnae-ga jo-a-ha-neun no-rae
意思我喜欢的歌。

阅读时看到一长串放在名词前面的东西，要先判断：

它们可能都在修饰最后那个名词。

礼貌 / 敬语

8. 礼貌层级 / 敬语系统

日语和韩语都非常重视说话关系。它们会通过句尾和词形表现礼貌、距离、尊敬。

8.1 日语：普通体和礼貌体

展开 / 收起

普通体：

行く。

romajii-ku
意思去。

礼貌体：

行きます。

romajii-ki-ma-su
意思去。

普通过去：

行った。

romajiit-ta
意思去了。

礼貌过去：

行きました。

romajii-ki-ma-shi-ta
意思去了。

否定礼貌：

行きません。

romajii-ki-ma-sen
意思不去。

8.2 日语尊敬语、谦让语

展开 / 收起

这部分先认识，不急着掌握。

尊敬语：抬高对方或第三方。

いらっしゃる

romajii-rassha-ru
意思去、来、在 的尊敬说法。

谦让语：降低自己，表示礼貌。

いただく

romajii-ta-da-ku
意思得到、吃、喝 的谦让说法。

8.3 韩语：해体、해요体、합니다体

展开 / 收起

韩语礼貌层级更明显。

非常口语/亲近：

가.

romanizationga
意思去。

日常礼貌：

가요.

romanizationga-yo
意思去。

正式礼貌：

갑니다.

romanizationgam-ni-da
意思去。

疑问正式：

갑니까?

romanizationgam-ni-kka
意思去吗？

尊敬成分：시 / si

가세요.

romanizationga-se-yo
意思请去 / 您去。

드세요.

romanizationdeu-se-yo
意思请吃。尊敬说法。
省略 / 词序

9. 省略：句子里不说出来的东西

日语和韩语经常省略主语、宾语，尤其是“我、你、这个”。

这对看 SNS 很关键。

9.1 日语省略

展开 / 收起

好き。

romajisu-ki

可能意思：喜欢。/ 我喜欢。/ 我喜欢这个。/ 我喜欢你。

行く？

romajii-ku

可能意思：去吗？/ 你去吗？/ 要去吗？

見た。

romajimi-ta

可能意思：看了。/ 我看了。/ 你看了吗？

9.2 韩语省略

展开 / 收起

좋아.

romanizationjo-a

可能意思：好。/ 喜欢。/ 我喜欢。/ 这个好。

가?

romanizationga

可能意思：去吗？/ 你去吗？

봤어.

romanizationbwa-sseo

可能意思：看了。/ 我看了。/ 你看了吗？

阅读时不要急着补成“我”或“你”。先看上下文。

省略 / 词序

10. 词序：日韩语的默认顺序

日语和韩语通常是 SOV 结构：

谁｜对什么｜做什么

也就是动词常在最后。

日语

私がご飯を食べる。

romajiwa-ta-shi ga go-han o ta-be-ru

直译：我 饭 吃。

韩语

내가 밥을 먹어.

romanizationnae-ga ba-beul meo-geo

直译：我 饭 吃。

中文和英语更常见的是 SVO：

中文我吃饭。

英语：I eat rice.

阅读日语/韩语时要习惯：

真正决定动作的词，经常在最后。

所以一句长句不要从前面开始逐字翻译到崩溃，可以先看最后：

最后是动作？状态？判断？否定？疑问？

指示 / 疑问 / 副词

12. 指示词：这个、那个、这里、那里

指示词有具体意义，但它们也承担结构定位功能：把谈话对象定位出来。

12.1 日语：こそあど体系

展开 / 收起

日语很常见：こ / そ / あ / ど

粗略理解：

こ = 近我，这个。

そ = 近你，那个；或刚提到的。

あ = 离双方都远，那个。

ど = 哪个。

例子：

これ / kore = 这个

それ / sore = 那个

あれ / are = 那个

どれ / dore = 哪个

ここ / koko = 这里

そこ / soko = 那里

あそこ / asoko = 那里

どこ / doko = 哪里

この曲 / kono kyoku = 这首歌

その曲 / sono kyoku = 那首歌

あの曲 / ano kyoku = 那首歌

どの曲 / dono kyoku = 哪首歌

12.2 韩语：이、그、저、어느

展开 / 收起

韩语粗略对应：

이 = 这。

그 = 那；也可指刚提到的。

저 = 那，离双方都远。

어느 = 哪个。

例子：

이거 / i-geo = 这个

그거 / geu-geo = 那个

저거 / jeo-geo = 那个

어느 것 / eo-neu geot = 哪个

여기 / yeo-gi = 这里

거기 / geo-gi = 那里

저기 / jeo-gi = 那里

어디 / eo-di = 哪里

指示 / 疑问 / 副词

展开 / 收起

口语 / SNS

14. 口语缩略、脱落、SNS写法

看 SNS 时会遇到大量非标准完整句。

14.1 日语常见

展开 / 收起

ている → てる

食べている → 食べてる

romajita-be-te i-ru → ta-be-te-ru
意思正在吃。

では → じゃ

本ではない → 本じゃない

romajihon de-wa na-i → hon ja na-i
意思不是书。

という → って

好きだという → 好きだって

romajisu-ki da to iu → su-ki datte
意思说是喜欢 / 听说喜欢。

romajita-be-te shi-ma-u → ta-be-cha-u
意思吃掉了 / 不小心吃了 / 还是会吃。

14.2 韩语常见

展开 / 收起

总框架 / 扫描顺序

16. 最实用的扫描顺序

以后看到一句日语/韩语，不要先逐字翻译。先按这个顺序扫：

第一步：先看最后

展开 / 收起

最后是动词、形容词、名词判断，还是疑问？

日语

行った。 = 去了。

行かない。 = 不去。

行きたい。 = 想去。

行く？ = 去吗？

韩语

갔어. = 去了。

안 가. = 不去。

가고 싶어. = 想去。

가? = 去吗？

第二步：找名词后面的小标签

展开 / 收起
日语が、は、を、に、で、の、と、から、まで、も、だけ。
韩语이/가、은/는、을/를、에、에서、의、와/과、부터、까지、도、만。

这些通常告诉你：

谁是主体。

谁是对象。

在哪里。

向哪里。

从哪里到哪里。

属于谁。

和谁。

也、只、都。

第三步：看有没有连接词

展开 / 收起
日语て、けど、から、ので、なら、たら、でも。
韩语고、지만、아서/어서、니까、면、도。

它们告诉你前后关系：

并列。

先后。

原因。

转折。

条件。

让步。

第四步：看有没有句尾语气

展开 / 收起
日语ね、よ、か、な、かな、じゃん。
韩语요、죠、네、지、까、니、냐。

它们告诉你：

是不是疑问。

是不是确认。

是不是提醒。

是不是感叹。

说话人和对方距离远近。

第五步：补省略

展开 / 收起

问自己：

这句话省略了“我”吗？

省略了“你”吗？

省略了“这个东西”吗？

需要靠上文补吗？

总框架 / 扫描顺序

17. 最简总表：看到小东西时先归类

17.1 名词后面出现的小东西

展开 / 收起

大概率是：

助词 / 关系标签。

它负责告诉你前面的名词是什么角色。

例子：

日语

猫が = 猫是主体。

猫を = 猫是对象。

猫に = 对猫 / 给猫 / 到猫那里。

猫の = 猫的。

猫と = 和猫。

韩语

고양이가 = 猫是主体。

고양이를 = 猫是对象。

고양이에게 = 对猫 / 给猫。

고양이의 = 猫的。

고양이와 = 和猫。

17.2 动词尾巴变了

展开 / 收起

大概率是：

时态、否定、愿望、可能、被动、使役、条件、礼貌。

日语

食べる = 吃。

食べた = 吃了。

食べない = 不吃。

总框架 / 扫描顺序

18. 这份表是否覆盖“几乎所有句子”

对于日常 SNS、短采访、评论、口语、普通歌词说明，这份结构地图可以覆盖大部分句子的分析入口。

但它不是“所有语法现象的最终全集”。因为语言里还有更细的东西，例如：

复杂敬语。

古语残留。

方言。

歌词里的省略和倒装。

网络梗。

文学性表达。

固定搭配。

拟声拟态词。

非常细的助词差异。

长句里的多层嵌套修饰。

不过作为入门阅读框架，它已经足够你把绝大多数真实句子先“拆开”。

你接下来看到一句话时，可以直接套这个模型：

内容词是什么？

名词后面有没有助词？

动词/形容词尾巴有没有变化？

中间有没有连接关系？

句尾有没有语气？

有没有省略？

只要能完成这六步，你就不是在面对一团字符，而是在面对一套可以拆解的结构。

总框架 / 扫描顺序

19. 最后压缩成一句话

日语和韩语的句子，不要先按中文逐字翻译。

应该先看：

谁 / 什么东西，被哪个小标签标出来；最后的谓词说它发生了什么、是什么状态；中间的连接成分说明前后关系；句尾说明语气和礼貌程度。

这就是最核心的阅读入口。
